# Design Decisions

This file documents design choices, deviations from the LFS book, and future plans for GagOS.

## Current Base

* **LFS version:** 13.1
* **Init system:** SysVinit
* **Architecture:** x86_64

## Deviations from LFS

No modifications have been made to the LFS build process so far.

## Future Plans

* Complete the LFS book.
* Evaluate whether to keep SysVinit or switch to systemd.
* Continue with BLFS.
* Add GagOS-specific configuration and software.
* Gradually turn the LFS base into a fully customized Linux distribution.
